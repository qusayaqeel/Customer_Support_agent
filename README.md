# Customer Support AI Agent 🤖

مساعد ذكي لخدمة العملاء مصمم باستخدام (FastAPI) ونماذج (Gemini 2.5 Flash) مع دعم لخاصية (Function Calling) للبحث عن المنتجات وحفظ الطلبات في قاعدة بيانات (SQLite) و (ChromaDB)، ومربوط مباشرة مع تطبيق (Telegram).

---

## 🛠️ المتطلبات (Prerequisites)
قبل تشغيل المشروع، تأكد من توفر التالي:
1. تثبيت لغة البايثون (Python 3.10+).
2. مفتاح API لـ Google Gemini.
3. إنشاء بوت تيليجرام من `@BotFather` والحصول على الـ Token.
4. تثبيت برنامج `ngrok` لفتح السيرفر للإنترنت.

---

## ⚙️ طريقة التثبيت والتشغيل (How to Run)

### 1. تثبيت المكتبات
قم بفتح الـ Terminal داخل مجلد المشروع واكتب الأمر التالي لتثبيت جميع المكتبات اللازمة:
```bash
pip install -r requirements.txt
```

### 2. إعداد المتغيرات البيئية (.env)
قم بإنشاء ملف باسم `.env` (إذا لم يكن موجوداً) أو انسخ محتوى `.env.example` إليه، وقم بوضع مفاتيحك فيه كالتالي:
```env
GEMINI_API_KEY=ضع_مفتاح_جوجل_هنا
TELEGRAM_BOT_TOKEN=ضع_توكن_تيليجرام_هنا
```

### 3. تشغيل السيرفر (FastAPI)
الآن، قم بتشغيل السيرفر المحلي بكتابة الأمر التالي:
```bash
uvicorn main:app --reload
```
*(هذا الأمر سيقوم بتهيئة قاعدة البيانات تلقائياً وتفعيل السيرفر على الرابط `http://127.0.0.1:8000`)*

### 4. ربط السيرفر بالإنترنت (ngrok)
افتح نافذة Terminal جديدة (مع ترك السيرفر يعمل في النافذة الأولى)، واكتب الأمر التالي لتشغيل نفق `ngrok`:
```bash
ngrok http 8000
```
بعد تشغيله، سيظهر لك رابط يبدأ بـ `https://` وينتهي بـ `.ngrok-free.app` (أو ما شابه). انسخ هذا الرابط.

### 5. إعداد الـ Webhook الخاص بتيليجرام
لكي يتمكن تيليجرام من إرسال الرسائل إلى سيرفرك، يجب إخباره برابط الـ ngrok الخاص بك عبر المتصفح.
استبدل الكلمات بين الأقواس ببياناتك، ثم انسخ الرابط وافتحه في المتصفح:
```text
https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook?url=<NGROK_URL>/webhook
```
مثال صحيح:
`https://api.telegram.org/bot123456:ABCDefGhi/setWebhook?url=https://abcd-1234.ngrok-free.app/webhook`

إذا ظهرت لك رسالة `Webhook was set`، فكل شيء يعمل بنجاح! افتح البوت على تيليجرام وابدأ المحادثة.

## 🧪 التجربة محلياً (CLI Testing)
إذا لم ترغب بتشغيل السيرفر وتيليجرام وتريد فقط اختبار المحادثة مباشرة في الـ Terminal، يمكنك ببساطة كتابة:
```bash
python chat.py
```
